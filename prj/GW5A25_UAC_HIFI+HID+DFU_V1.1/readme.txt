After opening the project file, you might see an "RTL Analysis Error" message in the upper right corner of the Hierarchy.
Solution:
1. In the left toolbar, select "Process," right-click "Synthesizer," and then select "Configuration."

2. Select "Synthesizer," then "General," and on the right, select "System Verilog 2017" under "Verilog Language," then click Apply.
